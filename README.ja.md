# 国公立大学ルーレット

[English README](./README.md)

国公立大学の中から1校をランダムに選出するルーレット Web アプリです。
均等抽選に加えて、**入試偏差値で重み付けされた抽選モード**（偏差値が高いほど選ばれやすい）を備えています。

- Vue 3 + TypeScript + Vite で構築
- UI は日本語がデフォルト、英語ロケールも完備
- GitHub Pages に静的サイトとして公開可能

## 機能

| 機能 | 説明 |
| --- | --- |
| 均等モード | すべての候補が完全に同じ確率で選ばれます |
| 偏差値重み付けモード | 偏差値が高いほど確率が指数的に大きくなります |
| 重み付けの強さスライダー | `0` で均等抽選と同一、`10` が最も偏ります |
| 絞り込み | 設置区分（国立 / 公立）、地域、偏差値の範囲 |
| 確率一覧 | 現在の設定における各候補の正確な確率を表示します |
| 抽選履歴 | 直近10件の結果を保持します |
| 多言語対応 | 日本語（既定）と英語。選択は `localStorage` に保存されます |

## 開発をはじめる

```bash
pnpm install
pnpm dev        # 開発サーバーを起動
pnpm test       # ユニットテストを実行
pnpm lint       # ESLint を実行
pnpm build      # 型チェックして dist/ にビルド
pnpm preview    # 本番ビルドをプレビュー
```

Node.js 22 以降と pnpm 10 を想定しています。

## 重み付けの仕組み

候補プールに対して、各大学の偏差値 `d` をプール内で正規化します。

```
normalised  = (d - 偏差値の最小値) / (偏差値の最大値 - 偏差値の最小値)
weight      = exp(strength * normalised)
probability = weight / weight の総和
```

この式から導かれる性質は次のとおりです。

- 重みは偏差値に対して単調増加するため、偏差値が高い大学が不利になることはありません。
- `strength = 0` ではすべての重みが `1` になり、均等抽選と完全に一致します。したがって両モードは
  同一のコードパスを共有します。
- *現在の* プールを基準に正規化するため、絞り込み後も重み付けが意味を持ちます。たとえば低偏差値の
  大学だけが残った場合でも、差が潰れません。
- すべての候補の偏差値が同じ場合は、重みが一律 `1` にフォールバックします。

抽選そのものは累積重みに対する逆関数法（`src/domain/picker.ts`）です。回転アニメーションは表示名を
切り替えているだけで、確定結果は実際の確率分布から一度だけ抽選されます。見た目の演出が確率に影響する
ことはありません。

## ディレクトリ構成

```
src/
  components/   粒度の細かい表示コンポーネント（1つの関心事につき1つ）
  composables/  リアクティブな状態: 抽選駆動、絞り込み状態、多言語ラベル
  data/         大学データセットと都道府県マスタ
  domain/       純粋なロジック: 絞り込み、重み付け、抽選（ユニットテスト対象）
  locales/      日本語・英語のメッセージカタログ
  types/        共有ドメイン型
  utils/        整形ヘルパー
```

`domain/` 層は Vue に依存しないため単体で検証でき、コンポーネントは composable を介してのみ
ドメイン層に依存します。

## デプロイ

`main` への push で [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) が起動し、
lint・テスト・ビルドを行ったうえで `dist/` を GitHub Pages に公開します。

リポジトリ側の初回設定: **Settings → Pages → Build and deployment → Source: GitHub Actions**。

本番のベースパスは [`vite.config.ts`](./vite.config.ts) のリポジトリ名から決まります。フォークや
リネームをした場合は `repositoryName` を更新してください。

## データに関する注意

データセットは学部入試を実施する国公立大学を対象としています。大学院大学（総合研究大学院大学、
北陸先端科学技術大学院大学、奈良先端科学技術大学院大学、政策研究大学院大学）は、重み付けの基準となる
入試偏差値が存在しないため除外しています。

偏差値は公開されている予備校の一覧表をもとにした **学部平均の目安値** です。公式な統計ではなく、
学部・科目・年度によって変動します。進路指導の根拠には使用しないでください。本サイトは娯楽目的です。

データを変更する場合は [`src/data/universities.ts`](./src/data/universities.ts) の行テーブルを
編集してください。各行は `[id, 日本語名, 英語名, 設置区分, 都道府県コード, 偏差値]` です。
